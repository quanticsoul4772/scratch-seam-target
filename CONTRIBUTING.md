# Contributing to scratch-seam-target

Thanks for your interest. This is a small scratch/pilot repo — right now it
contains only `README.md` and `LICENSE` — so contributing is deliberately simple.

## Dev environment setup

```
git clone https://github.com/quanticsoul4772/scratch-seam-target.git
cd scratch-seam-target
```

That's it. There is no build step, no package manager, and no dependencies to
install, because none exist yet.

## Running the test suite

There are no automated tests. Instead, do this manual verification before
proposing a change:

1. Clone the repo (see above).
2. Review the diff you are proposing.
3. Confirm that any claims in `README.md` or other docs still match the actual
   contents of the repo after your change.

## Commit / PR conventions

- Write clear commit messages that explain what changed and why.
- Keep PRs small and focused on a single change.
- Update `README.md` in the same PR whenever your change alters the repo's
  behavior or structure.
- Make sure docs and repo contents agree — don't reference files, tools, or
  processes that don't exist here.

## What's welcome

- Fixes and clarifications to `README.md` and other docs.
- Small structural improvements to the repo.
- Improvements to documentation clarity and accuracy.
- Early scaffolding, proposed and discussed via a small PR.

Conventions here are still being established and may change as the repo grows.
